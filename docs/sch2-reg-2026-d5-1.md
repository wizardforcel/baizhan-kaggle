# 银行定期存款响应预测（SCH2-REG-2026-D5-1）

## 一、比赛简介

### 1.1 比赛背景
本场比赛使用的是经典的银行电话营销数据集，记录银行通过电话向客户推销定期存款产品的历史。数据包含了客户的年龄、职业、婚姻状况、教育程度、信用违约记录、账户余额、住房贷款、个人贷款、联系渠道、联系日期、通话时长、营销次数、距上次联系天数、上次营销结果等属性。因为客户基数大、营销成本高，银行需要在营销前筛选出更可能接受产品的客户，以提升转化率并减少人工成本。数据本身的标签 `y` 表示客户是否接受产品 `1` 为接受、`0` 为拒绝，属于明显的不平衡二分类问题。

### 1.2 比赛目标
给定训练集中的客户属性，预测测试集客户是否会接受银行的定期存款产品。训练集特征包括 `age`、`job`、`marital`、`education`、`default`、`balance`、`housing`、`loan`、`contact`、`day`、`month`、`duration`、`campaign`、`pdays`、`previous`、`poutcome` 与 `id`，测试集只有特征列。目标是输出 `id` 与预测概率 `y` 的提交文件。

### 1.3 评价标准
从材料中的建模代码可以看出，模型采用 ROC-AUC 作为核心评估指标，同时也会参考准确率、F1、PR-AUC 等辅助指标。ROC-AUC 越高越好，意味着模型在不同阈值下区分正负样本的能力越强。材料中记录了一个基线 OOF AUC 约为 0.96823，后续的工程特征是在此基础上进行对比。

## 二、解题过程

### 2.1 数据探索（EDA）
我们首先把训练集和测试集读入，查看形状与列信息。训练数据没有缺失值，但正样本占比很低，属于不平衡问题。

```python
# 读取数据并查看基本信息

```

计数目标分布可以直接看到不平衡。箱线图显示 `duration` 与 `y` 关系强烈，接受客户的通话时长普遍更长。


我们还计算了数值为的 Spearman/Pearson 相关以及各类目特征的申购率，`poutcome`、`campaign`、`previous`、`age` 与 `balance` 的区分度相对最高。交叉表 `job × marital` 和 `job × education` 进一步揭示了职业与婚姻、教育在转化率上的交互差异。训练/测试分布做 KS 检验，确认大部分数值列的分布一致。

### 2.2 数据清洗
清洗的重点不是缺失处理，而是特征对齐与泄露意识。`duration` 是在通话结束后才知道的长度，在真实部署中不具备先验性，但材料中的代码将其保留作为离线实验指标，我们在文中明确标注了其数据泄露风险。

```python
# 基本清洗：去掉 id 并保持类别一致性
train = train.drop(columns=["id"])
test  = test.drop(columns=["id"])

# 对类别列统一为 category，以保证 train test 的水準一致
cat_cols = [c for c in train.columns if train[c].dtype == "object"]
for col in cat_cols:
    categories = pd.api.types.union_categoricals([train[col], test[col]])
    train[col] = pd.Categorical(train[col], categories=categories)
```

我们保留 `duration` 不作丢弃，但同时构造了 `long_call`、`short_call` 和 `duration_group` 作为衍生特征，用来实验不同时长阈值的影响。所有数值为列不做标准化，因为 LightGBM 能直接处理原始值。

### 2.3 模型训练与超参数调优
建模采用 LightGBM，二分类。先做特征工程，随后用分层 5 折交叉验证寻找稳定模型并评价 OOF AUC。

```python
# 特征工程函数，按材料中的思路新增衍生特征
def create_features(df):
    df = df.copy()
    df["is_senior"] = (df["age"] >= 60).astype(int)
    df["negative_balance"] = (df["balance"] < 0).astype(int)
    df["long_call"] = (df["duration"] >= 1000).astype(int)
    df["balance_signed_log"] = np.sign(df["balance"]) * np.log1p(np.abs(df["balance"]))
    df["senior_nonnegative_balance"] = ((df["age"] >= 60) & (df["balance"] >= 0)).astype(int)
    df["duration_log"] = np.log1p(df["duration"])
    return df
```

模型参数参照材料中的表现，学习率 0.03，num_leaves 63，feature_fraction 0.8，bagging_fraction 0.8，early stopping 100 轮。我们使用 StratifiedKFold 保证各折的正负比例一致。

```python
import lightgbm as lgb
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import roc_auc_score

lgb_params = {
    "objective":"binary",
    "metric":"auc",
    "learning_rate":0.03,
    "num_leaves":63,
    "min_child_samples":40,
    "feature_fraction":0.8,
    "bagging_fraction":0.8,
    "bagging_freq":5,
    "reg_alpha":0.1,
    "reg_lambda":0.1,
    "random_state":42,
    "n_jobs":-1
}
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_preds = np.zeros(len(train))
```

每折训练时会用早期停止，保存最佳迭代并把 OOF 预测累加到最终评价。训练结束后我们打印每折 AUC、平均标准差与 OOF AUC，并与材料中的基线 0.96823 对比。

```python
for fold, (trn_idx, val_idx) in enumerate(skf.split(X, y), 1):
    dtrain = lgb.Dataset(X.iloc[trn_idx], label=y.iloc[trn_idx])
    dvalid = lgb.Dataset(X.iloc[val_idx], label=y.iloc[val_idx])
    model = lgb.train(lgb_params, dtrain, num_boost_round=3000,
                      valid_sets=[dvalid],
                      callbacks=[lgb.early_stopping(stopping_rounds=100, verbose=False)])
    oof_preds[val_idx] = model.predict(X.iloc[val_idx], num_iteration=model.best_iteration)
    fold_auc = roc_auc_score(y.iloc[val_idx], oof_preds[val_idx])
    print(f"Fold {fold} AUC: {fold_auc:.5f}")
```

超参数调优采用梯度逐步缩小学习率与增加叶子数，通过交叉验证曲线评估。最终我们选择了在特征工程后仍保持稳定且不易过拟合的参数组合。特征重要性显示 `duration_log`、`poutcome`、`previous`、`age` 等位于前列，说明通话时长和历史营销记录是强预测信号。

使用 5 折的 OOF 预测计算整体 AUC，并绘制 ROC 曲线。测试集在所有折上平均得到预测概率，最终生成提交文件。

本文中我们完成了银行定期存款响应预测的完整建模流程。我们首先通过 EDA 明确了数据不平衡、通话时长与目标强相关以及类别特征的分布差异。其次我们在不丢弃原始特征的前提下做了类别对齐并构造了年龄、余额、时长相关的衍生特征，以捕捉非线性关系。接着使用 LightGBM 结合 5 折分层交叉验证进行训练与超参数调优，并以 ROC-AUC 为主评价指标。最后我们在验证集上得到与材料基线一致的水平，并在测试集上生成概率预测提交文件。
