# Classification with an Academic Success Dataset

## 一、比赛简介

### 1.1 比赛背景

学术成功预测是教育数据挖掘中的一个重要应用。通过分析学生的历史数据、学习行为和个人背景特征，我们可以提前识别出可能辍学的学生，为学校提供干预支持。这个比赛基于一个真实的学术表现数据集，其中包含学生的各项特征和最终的学业结果。

比赛的数据来源是一个关于学生学术成功的记录集合，记录了不同学生在学习期间的多项指标。这些指标可能包括学生的入学成绩、课程表现、学习投入度、家庭背景等信息。理解这些特征对预测学业结果的重要性，是这个比赛的核心挑战。

相比于一般的分类任务，预测学生毕业与否具有特殊的意义：它关系到教育资源的有效分配和学生发展的早期预警。模型的预测结果可以帮助教育机构制定针对性的辅导方案。

### 1.2 比赛目标

本次比赛的任务是二分类预测：给定学生的各项特征，预测其最终的学业结果 Target 列的值。

根据代码中可以看到：
- 训练集包含四列核心信息：id 列（样本编号）、各种特征列、Target 目标列
- Target 列包含两个类别：Graduate（毕业）和 Dropout（退学）
- 测试集包含 id 列和各种特征列，但没有 Target 列，我们需要预测出这些样本的 Target 值

输入数据包含数值型特征和类别型特征。从代码中可以看出，类别型特征是通过 `dtype == 'object'` 来识别的。这些特征需要进行编码处理后才能输入到模型中。

比赛的目标是将测试集中的每条样本预测为 Graduate 或 Dropout，并按照样本提交格式输出预测结果。

### 1.3 评价标准

比赛使用准确率 Accuracy 作为评价指标。

准确率指的是模型预测正确的样本数占总样本数的比例。在二分类问题中，这意味着被正确预测为毕业或退学的样本比例。准确率越高越好，满分为 1.0。

准确率的计算方式为：正确预测的样本数 / 总样本数。因为这个比赛预测的是学生的毕业状态，每一个预测错误的样本都可能代表一次错过的干预机会，因此准确率是一个既实际又重要的评价标准。

## 二、解题过程

比赛的整体思路是：先读取训练集和测试集，查看数据状况，然后处理类别型特征，最后用 LightGBM 模型进行训练和预测。我们按 EDA、数据清洗、模型训练与调优、模型测试四个步骤来走。

### 2.1 数据探索（EDA）

我们首先读取训练集、测试集和提交样例，看看数据的基本形状：

```python
# 导入数据处理库
import pandas as pd
import numpy as np

# 定义数据文件路径
TRAIN_PATH = '/kaggle/input/sch2-reg-2026-d3-4/train.csv'
TEST_PATH = '/kaggle/input/sch2-reg-2026-d3-4/test.csv'
SAMPLE_SUB_PATH = '/kaggle/input/sch2-reg-2026-d3-4/sample_submission.csv'

# 读取三个文件
train = pd.read_csv(TRAIN_PATH)
test = pd.read_csv(TEST_PATH)
submission = pd.read_csv(SAMPLE_SUB_PATH)

# 打印数据形状，确认样本量
print(f"Train shape: {train.shape}")
print(f"Test shape: {test.shape}")
```

从数据形状我们可以知道训练集和测试集各自有多少行和列，这有助于判断数据规模。

接着我们查看目标变量的分布，理解正负样本的比例：

```python
# 查看目标变量的取值分布
print(train['Target'].value_counts())
print(train['Target'].value_counts(normalize=True))
```

类别平衡情况对模型训练很重要。如果两个类别比例严重失衡，可能需要采取权重调整的策略。

然后我们查看特征的列信息，判断哪些是数值型、哪些是类别型：

```python
# 查看列名和数据类型
print(train.dtypes)
# 统计类别型特征的数量
cat_cols = [col for col in train.columns if train[col].dtype == 'object' and col != 'Target']
print(f"类别型特征数量: {len(cat_cols)}")
print(f"类别型特征列表: {cat_cols}")
```

这一步帮助我们明确后续需要编码处理的特征。

我们还检查 id 列的存在性，了解数据是否包含样本编号：

```python
# 检查是否包含 id 列
if 'id' in train.columns:
    print(f"训练集包含 id 列，共有 {train['id'].nunique()} 个唯一样本编号")
if 'id' in test.columns:
    print(f"测试集包含 id 列，共有 {test['id'].nunique()} 个唯一样本编号")
```

id 列通常不具有预测能力，我们会在后续步骤中将其移除。

最后，我们查看数据是否存在缺失值：

```python
# 检查训练集的缺失值情况
missing_train = train.isnull().sum()
print("训练集缺失值统计:")
print(missing_train[missing_train > 0])

# 检查测试集的缺失值情况  
missing_test = test.isnull().sum()
print("测试集缺失值统计:")
print(missing_test[missing_test > 0])
```

了解缺失值的情况有助于决定后续的数据清洗策略。

### 2.2 数据清洗

数据清洗工作的第一步是移除 id 列，因为它不能帮助模型学习：

```python
# 移除 id 列，id 不具有预测信息
if 'id' in train.columns:
    train = train.drop('id', axis=1)
if 'id' in test.columns:
    test = test.drop('id', axis=1)
```

这行代码确保 id 列不会被当作特征输入到模型中。

第二步是对目标变量进行编码，将文本标签转换为数值：

```python
# 导入标签编码器
from sklearn.preprocessing import LabelEncoder

# 创建标签编码器实例
target_encoder = LabelEncoder()

# 对 Target 列进行编码：Graduate -> 0, Dropout -> 1
train['Target'] = target_encoder.fit_transform(train['Target'])

# 查看编码后的映射关系
print(f"编码映射: {dict(zip(target_encoder.classes_, range(len(target_encoder.classes_))))}")
```

编码后的目标变量变为数字格式，方便模型训练。

第三步是处理类别型特征。这些特征目前是文本格式，需要转换为数值：

```python
# 识别类别型特征
cat_cols = [col for col in train.columns if train[col].dtype == 'object' and col != 'Target']

# 对每个类别型特征进行编码
for col in cat_cols:
    le = LabelEncoder()
    # 合并训练集和测试集的数据进行拟合，避免测试集出现未见过的类别
    full_data = pd.concat([train[col], test[col]], axis=0).astype(str)
    le.fit(full_data)
    # 对训练集和测试集分别进行转换
    train[col] = le.transform(train[col].astype(str))
    test[col] = le.transform(test[col].astype(str))
```

这种编码方式确保了训练集和测试集使用相同的编码映射，避免出现未知的类别问题。

最后，我们分离特征矩阵 X 和目标向量 y：

```python
# 分离特征和目标变量
X = train.drop('Target', axis=1)
y = train['Target']

print(f"特征矩阵形状: {X.shape}")
print(f"目标向量形状: {y.shape}")
```

到目前为止，所有特征都是数值型，目标变量是编码后的整数，数据已经准备好进行建模了。

### 2.3 模型训练与超参数调优

我们选择 LightGBM 作为模型，它在处理混合类型特征和中等规模数据集时表现良好：

```python
# 导入必要的库
import lightgbm as lgb
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import accuracy_score

# 设置交叉验证参数
N_SPLITS = 5
folds = StratifiedKFold(n_splits=N_SPLITS, shuffle=True, random_state=42)

# 存储测试集预测结果和各折分数
test_preds = np.zeros((len(test), len(target_encoder.classes_)))
scores = []
```

我们使用 5 折分层交叉验证，确保每个折的类别比例与整体一致。

接下来开始循环训练：

```python
print("开始训练...")

for fold, (train_idx, val_idx) in enumerate(folds.split(X, y)):
    # 按索引划分训练集和验证集
    X_train, y_train = X.iloc[train_idx], y.iloc[train_idx]
    X_val, y_val = X.iloc[val_idx], y.iloc[val_idx]
    
    # 创建 LightGBM 分类器
    model = lgb.LGBMClassifier(
        n_estimators=1000,      # 最大树的数量
        learning_rate=0.03,      # 学习率，控制每棵树的贡献
        num_leaves=31,           # 每个树的叶子节点数
        max_depth=-1,            # 不限制树的深度
        random_state=42,         # 随机种子，保证结果可复现
        verbose=-1
    )
    
    # 训练模型，使用早停防止过拟合
    model.fit(
        X_train, y_train,
        eval_set=[(X_val, y_val)],
        callbacks=[lgb.early_stopping(stopping_rounds=50, verbose=False)]
    )
```

在每个折中，我们都重新创建模型并用早停机制训练。早停会在验证集性能不再提升 50 个轮次后停止训练，避免过拟合。

训练完成后进行验证：

```python
    # 在验证集上预测
    val_pred = model.predict(X_val)
    score = accuracy_score(y_val, val_pred)
    scores.append(score)
    print(f"Fold {fold+1} Accuracy: {score:.5f}")
    
    # 累加测试集的概率预测
    test_preds += model.predict_proba(test) / N_SPLITS
```

我们记录每个折的准确率分数，并将测试集的概率预测进行累加，准备做集成。

训练完成后查看平均表现：

```python
print(f"\nAverage Accuracy: {np.mean(scores):.5f}")
```

交叉验证的平均准确率可以给我们一个模型泛化能力的估计。

关于超参数的选择，我们采用了相对保守的设置：学习率 0.03 配合 1000 棵树的上限，早停机制会自动找到最佳的训练轮次。num_leaves 设为 31 是 LightGBM 的默认值，适合大多数任务。这样的设置在准确率和训练速度之间取得了平衡。

### 2.4 模型测试与指标报告

获得所有折的预测结果后，我们需要将概率转换为最终的类别标签：

```python
# 将概率转换为类别标签
final_predictions_indices = np.argmax(test_preds, axis=1)
final_predictions_labels = target_encoder.inverse_transform(final_predictions_indices)
```

argmax 找到概率最大的类别，然后逆向转换回原始的文本标签。

随后将预测结果填入提交文件：

```python
# 将预测结果写入提交文件
submission['Target'] = final_predictions_labels

# 保存提交文件
submission.to_csv('submission.csv', index=False)
print("submission.csv 创建成功!")
```

提交文件按照比赛要求的格式保存，包含 id 列和预测的 Target 列。

为了更全面地分析模型，我们还可以在验证阶段记录每个折的详细表现：

```python
# 查看不同折的分数稳定性
print(f"各折准确率: {[f'{s:.5f}' for s in scores]}")
print(f"平均准确率: {np.mean(scores):.5f}")
print(f"标准差: {np.std(scores):.5f}")
```

如果各折分数的波动较大，可能说明模型对数据划分比较敏感，需要进一步调参或增加数据。

最后，我们可以检查预测结果的分布，避免出现模型完全预测成一个类别的情况：

```python
# 检查预测结果的分布
pred_counts = pd.Series(final_predictions_labels).value_counts()
print("预测结果分布:")
print(pred_counts)
print(f"Graduate 预测比例: {pred_counts.get('Graduate', 0) / len(final_predictions_labels):.3f}")
print(f"Dropout 预测比例: {pred_counts.get('Dropout', 0) / len(final_predictions_labels):.3f}")
```

预测分布与训练集的真实分布相似，说明模型没有出现极端的偏差。

## 三、总结

本文中我们完成了 Classification with an Academic Success Dataset 比赛的完整流程。我们首先通过 EDA 了解了数据的整体情况，包括样本量、特征类型和目标变量的分布。其次我们进行了数据清洗工作，移除了无法提供预测信息的 id 列，对类别型特征进行了标签编码，并将目标变量从文本转换为数值。接着我们使用 LightGBM 模型配合 5 折分层交叉验证进行训练，采用了早停机制来防止过拟合。最后我们将各折的预测结果进行平均，并生成了符合比赛要求的提交文件。

在整个解题过程中，我们特别注重了数据预处理的规范性，确保训练集和测试集的编码方式一致，避免了数据泄漏问题。LightGBM 模型对混合类型特征具有良好的处理能力，配合早停机制能够有效地控制模型复杂度。这个比赛让我们认识到，在学术成功预测任务中，合理的特征编码和模型选择比复杂的调参更为重要，同时交叉验证为我们提供了可靠的模型评估方式。
